## 优先收尾顺序

1. 核对专用 Doris、原始文件和独立参考；按 v1.0.4 升级语义视图，生成新来源证书。
2. 用最终 JAR 跑当前 94／79／172 组真实矩阵，比较完整结果与顺序、缺值、解释、性能和稳定性；失败时先保留工件并修复。
3. 在认可范围明确后补比赛正确率和性能评测；不需要以更多重复次数替代必要覆盖。
4. 上传最终版本并核对 CI，打包绑定本批身份的 JAR／源码／证据，按校验说明检查恢复。
