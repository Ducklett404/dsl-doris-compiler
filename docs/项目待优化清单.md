## 6 项项目侧待办

### T1 · P0：多指标组合与数值边界验收

- [ ] 将均价、前后复权收盘价、换手率、市值、资金与既有价格、MA、RSI 组合，补充多个窗口同时使用的场景。
- [ ] 覆盖 AND/OR、精确阈值及阈值两侧、百分比与单位、NULL 参与条件、稀疏观察和资金来源缺行；保留已支持语法的边界，不在本轮扩大冻结语义。
- [ ] 用手工公式和原始记录构造独立参考，在便携夹具、隔离 Doris 夹具和现有官方数据上比较完整证券列表、顺序、缺失统计及解释。

完成标准：新增矩阵全部通过；发现差异先修复并添加回归；每个失败或排除场景有明确原因。现有 94 组逐字段场景保留。真实数据未出现的边界通过隔离夹具补测，并注明证据类型。

### T2 · P0：排名、LIMIT、跨证券查找及次数组合回归

- [ ] 把新增逐字段覆盖的指标加入 RANK/DENSE_RANK/ROW_NUMBER 和 LIMIT，检查并列、NULL、排序方向及确定性结果。
- [ ] 扩展 queryData：存在或缺失目标、文本代码前导零、市场区分、目标日期缺行，以及与当前证券条件混合。
- [ ] 扩展已支持的 CONS/EXIST 次数条件：合法负资金、未知条件不计命中、观察不足、次数结果与输入缺值分别披露。
- [ ] 覆盖沪深京、市场并集/排除及多个日期，避免只验证最新日或结果前几行。

完成标准：新组合在真实 Doris 执行，与独立参考的完整结果及顺序一致；跨证券解释无法完整展开时仍明确标记 `PARTIAL_DETAIL`，不把有限解释宣称为全量原因分析。

### T3 · P0：统一现有数据的项目验收入口

- [ ] 将来源验证、证书生成、字段与组合矩阵执行、独立结果/解释核对、严格拒绝门禁和中文汇总串成可复跑命令。
- [ ] 固定并记录代码、JAR、注册表、字段规则、证书、CSV/manifest 和矩阵哈希；使用新的输出目录，失败即停止，保留失败工件。
- [ ] 核对各子命令的退出码与机器报告状态；明确区分项目通过、预期正式 BLOCKED、环境未运行和真正失败。以实际命令契约为准，不把不同入口的退出码混用。
- [ ] 恢复执行只复用哈希一致且通过的阶段；验证来源变化、证书过期/损坏、结果损坏和临时库清理失败能被发现。

完成标准：在当前环境从新报告目录完成一次完整项目验收，并验证至少一次失败及恢复路径。已有 `scripts/doris/run_official_data_route.py` 编排的是此前特征和性能诊断；已有统一离线自测也继续保留。本项补齐最新项目来源、19 字段及组合验收链路，不另造一个绕过正式门禁的入口。

- [ ] 在完成 T1/T2 的最终版本上，分开测主查询、缺值统计、样本解释及端到端耗时；采集可获得的 Doris Profile 和内存证据。
