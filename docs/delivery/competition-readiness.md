## 要求对照

| 要求 | 实现／证据 | 当前判断与缺口 |
|---|---|---|
| 复杂 DSL SQL 正确率 ≥95% | 独立参考、黄金集、字段／组合／排名矩阵；历史 94 组真实字段查询通过 | 正式门禁 0 组、准确率 null；必须明确认可范围、分母与结果参考后评测 |
| 19 年查询加速 ≥10 倍 | 历史特征路线代表查询热缓存 P95 比值 86.74x，结果和顺序一致 | 当时 JAR／机器／目录；需最终版本、认可基线与缓存条件复测，并披露构建成本 |
| 新指标／函数接入核心引擎改动 0 行 | 直接字段、模板计算、已有窗口 lowering 的配置扩展和 CI 门禁 | 同类配置扩展有证据；全新语义及任意函数须另行实现、验证 |
| 编译端到端 P95 <50ms | 上传前正式 DSL 5,000 次缓存旁路 P95 0.2933ms，绑定本机 JAR；历史基准另列 | 本机编译延迟达标；远程最终构建和其他目标环境需使用各自绑定证据 |
| SQL 执行并返回结果 ≤10 秒 | 超时、扫描／内存／返回预算和历史查询测量 | 10 秒限制不等于全部查询成功；需实际记录超时／拒绝／成功及分阶段耗时 |
| 可运行原型及完整材料 | 源码、JAR、CLI／HTTP／Docker、说明、示例、Markdown 输出和校验包 | 形式基本齐全；原始数据和专用 Doris 环境单独准备 |

## 可使用的项目介绍

本项目实现行情选股槽位 DSL 到参数化 Doris SQL 的编译和受控执行，包含语法／类型检查、窗口与候选集排名、访问路径选择、缺失原因说明和可追溯验收。现有执行范围为 19 项已映射指标、MA／RSI、11 类函数、沪深京及确定日期；行业、财务等缺少来源的能力明确排除。2026-10-10 本机重建 334 项 Java 测试通过，8 项真实数据库集成测试未运行。历史真实数据诊断与性能记录说明了项目能力，最终比赛正确率和性能达标仍需认可范围及同版本证据。
