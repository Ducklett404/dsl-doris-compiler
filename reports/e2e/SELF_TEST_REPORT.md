## 已发现并修正的问题

1. 原执行结果只记录编译和整体查询耗时，无法区分排队、EXPLAIN、执行和返回；现已拆分。
2. 原执行器允许管理账号，现受控入口会检查授权并拒绝非只读身份。
3. 原执行器只有超时/返回行限制，没有扫描量门禁；现增加 EXPLAIN 预检和 Doris Workload Policy。
4. 原 HTTP 编译错误统一返回 400，现区分语法 400 和语义 422，并为数据、超时、Doris、配额建立独立状态码。
5. 原结果缺少可审计标识；现记录 SQL 指纹、三段数据版本、编译器版本、EXPLAIN 与 Profile 摘要。
