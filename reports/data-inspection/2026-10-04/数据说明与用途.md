## 能支持什么

1. **正式 DSL 结果验收。** 在同一快照上比较编译器 SQL、独立参考计算和官方标准结果。
   当前注册表已有 19 个精确指标及 MA/RSI 两类参数化指标；已有 SQL 支持窗口、排名和计数。
2. **历史指标与筛选查询。** 例如 20/60 日收盘均线、区间新高新低、成交量排名、连续满足条件、
   主力净流入累计。具体结果要遵循可用日期、单位、窗口不足和 NULL 契约。
3. **真实数据边界回归。** 验证历史不足、行情缺行、字段空值、衍生数据缺失以及异常哨兵处理。
4. **Doris 性能评测。** 基础行情具有约 20 年跨度，可比较全历史窗口与 v2 特征访问，测量
   EXPLAIN 扫描量、查询 P95、缓存及内存，并输出可复现报告。
5. **后续扩展指标。** CSV 中存在的估值、竞价及资金衍生字段可以进入候选映射清单；须先确认
   官方定义、单位、有效样本和时间覆盖，再加入注册表和黄金集。字段存在不表示当前编译器已经支持。

日级行情可以作为后续历史策略研究的输入；可靠收益回测还需另行明确交易规则、停牌/涨跌停、
成本、证券历史状态及复权有效性。本次不把数据存在等同于完整回测条件具备。

## 已确认的数据边界

| 事实 | 对用途的影响 |
|---|---|
| 代码表 hyBlkRefName 全部为空 | 缺少行业分类，无法验证有实际行业成员的行业聚合和行业排名 |
| stFlag、kcbFlag、gemFlag、bShareFlag 全部为 0 | 这些标志没有区分能力，不能直接据此可靠完成相应证券分类 |
| qfq/hfq 因子只有 (1,0,1,0) | 可以验证恒等公式，不能验证除权除息后的非默认复权效果 |
| 基础表 closePx 有效覆盖约 99.91%，lastPx 仅约 21.35% | 收盘窗口与最新价查询的可用性不同；不能擅自用收盘价填补最新价 |
| 基础表 outerVol、innerVol 全空 | 该快照无法支持依赖内外盘数据的有效结果验证 |
| 主力净流入有效覆盖约 97.91%；分钟涨速仅约 1.51%–2.42% | 可以优先验证主力净流入；分钟摘要覆盖稀疏，不能当作完整分时序列 |
| 衍生字段出现 -999999 | 要按对应字段的官方缺失值约定转为 NULL，不参与正常数值聚合 |
| 数据截至 2026-04-14 | 评价日需在实际覆盖范围内；此快照不提供之后的行情 |
| 证券信息表没有历史生效区间；只有三张行情相关表 | 严格历史分类和财报点时查询还需额外资料；目前没有完整财报、公告或独立逐笔/分时表 |

项目当前口径为价格 `/10000`、成交额 `/100`、指定比率 `/10000`。这些是现有数据契约和样本
交叉检查所采用的口径；官方数据字典仍应作为最终确认依据，特别是资金字段和非默认复权加项。
